# Expense Tracker - Explanation

This is a simple web application that helps you keep track of your money. You can add income (money you earn) and expenses (money you spend), and the app will calculate your balance automatically.  

- **Add Transactions:** Enter a name for the transaction (like "Salary" or "Groceries") and an amount.  
  - Positive numbers are income.  
  - Negative numbers are expenses.  
- **View Balance:** The app shows your total balance, total income, and total expenses.  
- **Transaction History:** All your transactions are shown in a list with color codes:  
  - Green for income  
  - Red for expenses  
- **Delete Transactions:** You can remove any transaction from the history.  
- **Save Data:** The app uses your browser's local storage to save transactions. This means your data stays even if you refresh the page or close the browser.  

The interface is easy to use and works on both computers and mobile devices. It's a great tool to learn how to manage personal finances and practice HTML, CSS, and JavaScript.
